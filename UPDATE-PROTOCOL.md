# Update Protocol

Update when verified events change: the current workstream/task, a blocker, release/deployment state, repository ownership, incident/security state, or material roadmap state. Not for every commit.

1. Verify canonical/external state.
2. Update the canonical owner.
3. Update machine state here.
4. Reconcile CURRENT.md.
5. Add a handoff only when continuity requires it.

Handoff minimum: verified state; completed work; files/PRs/SHAs; failed checks/blockers; constraints; one precise next action.
