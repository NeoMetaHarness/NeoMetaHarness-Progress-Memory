# Session Start

Before doing work:
1. Read `machine/current-state.json`, `machine/current-task.json`, `machine/blockers.json`, `machine/workstreams.json`.
2. Use `ROUTER.md` to find the canonical owner, then read that repo's `AGENTS.md`.
3. Verify external/current state before changing anything.
4. Reuse an existing workflow or Skill when one fits.
5. Execute, verify, capture evidence.
6. Update Progress-Memory only after a verified state change.

If state is ambiguous, do not invent completion.
